## О проекте

В работе исследуется периодичность булевых функций, заданных полиномами Жегалкина.

Рассматривается подстановка π блочного шифра «Кузнечик» из ГОСТ Р 34.12–2015. Эта подстановка задаёт 8 координатных булевых функций от 8 переменных. Для каждой функции строится полином Жегалкина, после чего применяется алгоритм поиска периодов по полиномиальному представлению.

Цель проекта — проверить, имеют ли координатные функции подстановки ненулевые периоды, а также существуют ли общие ненулевые периоды для всех восьми функций.

## Что реализовано

В проекте реализованы следующие этапы:

* получение 8 булевых функций из подстановки π шифра «Кузнечик»;
* построение таблицы истинности для координатных функций;
* построение полиномов Жегалкина с помощью быстрого преобразования;
* реализация алгоритма поиска периодов полиномов Жегалкина;
* построение систем линейных уравнений над GF(2);
* решение систем методом Гаусса над GF(2);
* поиск базиса пространства периодов для каждой функции;
* поиск общих периодов для всех восьми функций;
* измерение времени работы и пикового потребления памяти.

## Математическая основа

Функция алгебры логики рассматривается как отображение:

```text
f : E_2^n -> E_2
```

Каждая булева функция единственным образом представляется полиномом Жегалкина над полем GF(2).

Набор `a` называется периодом функции `f`, если для любого входа `x` выполняется:

```text
f(x + a) = f(x)
```

Множество всех периодов функции образует линейное пространство над GF(2). Поэтому задача поиска периодов сводится к построению и решению однородной системы линейных уравнений.

## Используемый алгоритм

В работе используется алгоритм поиска периодов полиномов Жегалкина, предложенный С. Н. Селезнёвой.

Основная идея алгоритма:

1. выбрать старший моном полинома;
2. построить по нему специальный полином;
3. извлечь линейные уравнения, которым должны удовлетворять периоды;
4. уменьшить степень текущего полинома;
5. повторять процесс до получения константы;
6. решить полученную систему линейных уравнений над GF(2).

## Результаты

Для каждой из восьми координатных функций подстановки π было найдено пространство периодов.

Результат:

* размерность пространства периодов каждой функции равна 0;
* ненулевые периоды для отдельных функций не найдены;
* общих ненулевых периодов для всех восьми функций не обнаружено.

Это означает, что все восемь координатных функций подстановки «Кузнечик» не являются периодическими в рассматриваемом смысле.

## Основные функции

В проекте используются следующие функции:

* `create_truth_table` — строит таблицу истинности координатных функций подстановки;
* `fast_transform` — строит коэффициенты полинома Жегалкина по таблице истинности;
* `algorithm_A1` — реализует алгоритм поиска периодов по полиному Жегалкина;
* `multiply_polinoms` — перемножает полиномы над GF(2);
* `get_max_weight_mask` — выбирает моном максимальной степени;
* `build_gk` — строит вспомогательный полином на шаге алгоритма;
* `find_periods_basis` — находит базис пространства периодов одной функции;
* `find_common_periods` — ищет общие периоды нескольких функций;
* `analyze_permutation` — запускает полный анализ подстановки.
